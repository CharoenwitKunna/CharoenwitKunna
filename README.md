# Charoenwit Kunna

Builder of browser games, automation bots, and networking tools. I ship small, fast projects end-to-end — idea to live deployment.

## What I Build

- **Browser games** — arcade, tower defense, and physics titles built with Canvas and vanilla JS
- **Game backends & economies** — 24/7 bots, leaderboards, and server tooling
- **Networking & security tooling** — mesh coordinators, VPN factory scripts, C2 infrastructure experiments
- **Automation** — YouTube tooling, APIs, scrapers

## Highlighted Projects

- [Sticky-Orbit](https://github.com/CharoenwitKunna/Sticky-Orbit) — physics orbit game, with a [global leaderboard](https://github.com/CharoenwitKunna/StickyOrbitLeaderboard)
- [infinite-maze-td](https://github.com/CharoenwitKunna/infinite-maze-td) — endless maze tower defense in the browser

- [flashmaths](https://github.com/CharoenwitKunna/flashmaths) — speed math practice game
- [ForzerC2](https://github.com/CharoenwitKunna/ForzerC2) — WebSocket mesh coordinator: register / map / signal / command relay
